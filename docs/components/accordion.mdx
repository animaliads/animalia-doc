# <h1 style={{ fontSize: "3rem" }}>Accordion</h1>

<div style={{ maxWidth: '60%' }}>

O `Accordion` organiza seções de conteúdo relacionadas e permite revelar ou ocultar cada seção. Ele reduz a extensão visual da página sem remover o acesso às informações.

### Quando usar

- Para dividir um conteúdo extenso em seções relacionadas e fáceis de examinar.
- Quando os títulos das seções forem suficientes para antecipar o conteúdo oculto.
- Quando a pessoa puder consultar uma seção sem precisar visualizar todas as demais.

### Quando não usar

- Para esconder informações essenciais à conclusão de uma tarefa.
- Para representar etapas sequenciais; nesse caso, utilize o [Stepper](/docs/components/stepper).
- Quando as seções precisarem ser comparadas simultaneamente.

### Anatomia

1. **Cabeçalho:** controle que apresenta o título da seção.
2. **Ícone indicador:** comunica visualmente se a seção está expandida ou recolhida.
3. **Painel:** região associada ao cabeçalho que recebe texto ou um conteúdo substituível.
4. **Divisor:** separa visualmente itens consecutivos.
5. **Controle geral opcional:** permite abrir ou fechar todos os itens.

### Variantes e estados

O Figma prevê conteúdo do tipo **Text** ou **Slot (replace me)**. Os cabeçalhos podem estar **Collapsed** ou **Expanded**, combinados com os estados **Default**, **Hover**, **Pressed**, **Focused** e, para itens recolhidos, **Disabled**.

### Comportamento e responsividade

- O acionamento do cabeçalho alterna somente o painel associado.
- O ícone deve acompanhar imediatamente a mudança entre recolhido e expandido.
- A expansão deve deslocar o conteúdo seguinte, sem sobreposição.
- Em larguras reduzidas, título e conteúdo podem quebrar linha; o controle permanece com toda a largura disponível.
- Os comandos “Abrir todos os itens” e “Fechar todos os itens” só devem aparecer quando houver vários painéis e a ação coletiva for útil.

## Boas práticas

- Use títulos curtos, específicos e diferentes entre si.
- Organize os itens em uma ordem previsível.
- Preserve o estado expandido durante interações que não alterem o contexto.
- Não coloque um Accordion dentro de outro.
- Não dependa apenas da direção do ícone para comunicar o estado.

## Referência de variáveis do Figma

Estas variáveis descrevem a composição visual no Figma e **não devem ser interpretadas como custom properties CSS públicas**.

| Variável no Figma | Aplicação observada |
| --- | --- |
| `Ani Accordion/Manager/--background` | Fundo do controle geral |
| `Ani Accordion/Manager/--text-color` | Texto do controle geral |
| `Ani Accordion/Manager/--icon-color` | Ícone do controle geral |
| `Ani Accordion/Item/--background` | Fundo do item |
| `Ani Accordion/Item/--text-color` | Título do item |
| `Ani Accordion/Item/--icon-color` | Indicador de expansão |
| `Ani Accordion/Item/--divider-color` | Divisor entre itens |
| `Ani Accordion/Item/Focus/--outline-focus` | Indicador de foco |
| `Ani Accordion/Item/Disabled/--background-disabled` | Fundo desabilitado |

Os estados Hover e Pressed também possuem variáveis próprias de fundo, texto e ícone.

## Acessibilidade

- Cada cabeçalho deve ser operável por teclado com `Enter` ou `Space`.
- O controle deve expor seu estado com `aria-expanded` e referenciar o painel associado com `aria-controls`.
- O título precisa continuar compreensível fora do contexto visual.
- Todos os controles interativos participam da ordem natural de foco e apresentam foco visível.
- A implementação deve seguir o [padrão Accordion do WAI-ARIA APG](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/).

:::caution Validação técnica
O comportamento exato de expansão única ou múltipla e dos comandos coletivos deve ser confirmado na implementação.
:::
