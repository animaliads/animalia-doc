  ### Quando usar

  - Para agrupar informações e ações que pertençam a um mesmo assunto em uma unidade lógica.
  - Como porta de entrada para conteúdos mais detalhados ou resumos de tópicos.
  - Quando a visualização em blocos facilita a escaneabilidade de uma página (ex: feeds ou dashboards).

  ### Quando não usar

  - Quando a informação for muito densa e não puder ser resumida; prefira uma página inteira.
  - Evite aninhar um card dentro de outro (*nesting*) para não confundir a hierarquia visual.
  - Não utilize cards para ações isoladas que poderiam ser resolvidas apenas com um botão ou link simples.

  ### Variantes (Tipos)

  O componente **card** prevê duas variações principais:

  - **Read-only**: Quando o card é apenas um agrupador das informações. Pode conter elementos interativos dentro dele (links/botões), mas não há interação no card propriamente dito.
  - **Interactive**: Quando o card em si é o elemento interativo, podendo assumir as características de:
    - **Link**: Direciona a pessoa para outra página.
    - **Selectable**: O card pode ser selecionado em um conjunto de cards.

  ### **Comportamento e Responsividade**

  - **Conjunto de cards**: Ao utilizar cards em conjunto, as larguras devem ser padronizadas.
  - **Organização**: Seguem uma sequência lógica: da esquerda para a direita, de cima para baixo, iniciando no canto superior esquerdo.
  - **Responsividade**: Os cards devem se adaptar à largura do container ou grid, podendo empilhar verticalmente em dispositivos móveis.

  ## Propriedades Customizáveis (Tokens)

  Apenas a variante **Interactive** assume os estados: **Normal**, **Hover**, **Focused** e **Pressed**.

  ### Card (Geral)

  | **Propriedade** | **Descrição** | **Valor Padrão** |
  | --- | --- | --- |
  | `--background` | Cor de fundo do contêiner | `$color-neutral-light-00` |
  | `--border-color` | Cor da borda do card | `$color-neutral-mid-40` |
  | `--border-width` | Espessura da borda | `$border-width-sm` |
  | `--border-radius` | Arredondamento dos cantos | `$border-radius-md` |
  | `--padding` | Espaçamento interno | `$spacing-md` |

  ### Interactive / Selectable

  | **Propriedade** | **Descrição** | **Valor Padrão** |
  | --- | --- | --- |
  | `--shadow-hover` | Sombra aplicada no estado de hover | `$shadow-level-2` |
  | `--outline-color-focus` | Cor do anel de foco | `$color-action-focus` |
  | `--background-selected` | Cor de fundo no estado selecionado | `$color-brand-01-lighter` |
  | `--border-color-selected` | Cor da borda no estado selecionado | `$color-action-default` |

  ## Desenvolvimento

  Caso você já tenha seguido o passo a passo descrito em [Começando](/docs/about/getting-started), você pode pular esta instalação e ir direto para o tópico [Como utilizar](#como-utilizar). Para instalar o componente de forma isolada em seu projeto, utilize o comando abaixo: 
  
  ```
  npm install @animaliads/ani-card
  ```

  ### Como utilizar

  A implementação requer a importação do módulo principal, variando conforme a biblioteca ou framework utilizado. Após a configuração, utilize o elemento `ani-card` no seu código:

  ```html
  <ani-card type="interactive" variant="selectable">
    <div slot="header">Título</div>
    <div slot="content">Conteúdo do card</div>
  </ani-card>
  ```

  >Para aplicar o tema padrão, é obrigatória a instalação e o uso dos pacotes `@animaliads/animalia-brand` e `@animaliads/css-tokens`. Você pode conferir exemplos práticos no [Live Demo](#live-demo).

  ### Customização

  Para adaptar visualmente o componente, você pode sobrescrever as propriedades customizáveis via CSS:

  ```css
  ani-card {
    --border-radius: 8px;
    --background-color: #ffffff;
  }
  ```

  >Para saber quais são as propriedades disponíveis, consulte a aba de [Estilização](/docs/components/card#custom-properties).

  ## Acessibilidade (Padrão AAA)

  ### Interação por Teclado

  Em variantes *interactive*, permite seleção através da tecla `Space` ([WCAG 2.4.1](https://www.w3.org/WAI/WCAG21/Understanding/bypass-blocks.html)).

  | **Tecla** | **Função** |
  | --- | --- |
  | `Tab` | Navega sequencialmente entre os cards interativos. |
  | `Enter` / `Space` | Ativa a ação de link ou alterna o estado de seleção. |

  ### Operável e Compreensível

  - **Medidas Relativas**: Utiliza medidas flexíveis para se adequar às preferências de quem utiliza o sistema.
  - **Nome e Função**: Desenvolvido com controles padrões HTML, permitindo identificação por tecnologias assistivas ([WCAG 4.1.2](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value)).
  - **Foco Visível**: Possui espessura superior a **2px** e não fica escondido por outros elementos ([WCAG 2.4.12](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-enhanced.html)).
